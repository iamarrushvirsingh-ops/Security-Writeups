# Windows Basics

- Early computers ran MS-DOS, which showed a black screen with a command line (CLI) but no graphical interface (GUI).

## Logging In and Authentication

- Before you can use the Windows desktop, you must authenticate (prove your identity) to the system.
- Authentication checks who you are and decides what you're allowed to do once logged in.
- Each user gets a set of permission levels that control their access to files, settings and system features. Windows commonly uses these account types:
    - **Guest**: A limited account for temporary access, with minimal permissions and no ability to change system settings.
    - **Standard**: An account for everyday tasks, like running apps and changing personal settings, without access to system-wide changes.
    - **Administrator**: A privileged account with full control over the system, including installing software, changing configuration and managing users.

## Core Components of the OS

1. **Task View**: Lets you see all open windows and quickly switch between them.
2. **Notifications**: Shows computer and app notifications. Network and other quick settings can also be accessed here.

- There are built-in tools like File Explorer and Notepad provided by the OS.
- You can find system information in the "About your PC" section of the Settings app.
- Other features like Search and the Start Menu also come by default as part of the OS.

## Updating and Managing Apps

- You can download and update applications through the Microsoft Store.
- You can also install applications using installers. These are usually `.exe` or `.msi` files, or zip files.
- There are many ways to uninstall apps, and some apps even have their own built-in uninstaller.

## Control Panel and Settings

There are two main ways to change how Windows works:

1. **Windows Settings**: The modern, central place for configuring system, device, personalisation and security settings.
2. **Control Panel**: The older (legacy) management interface, still needed for some specific admin tasks.

- Both let you view and change how your Windows system works.

## Task Manager

- **Task Manager** is a built-in Windows tool that shows you what's happening on your system in real time.
- It lets you see running applications and background processes, and check system performance like CPU and memory usage.

Task Manager has five tabs:

1. **Processes**: Running apps and background processes, and the resources they use.
2. **Performance**: Graphs and stats for system resources like CPU, memory and network.
3. **Users**: Currently logged-in users and the resources they use.
4. **Details**: A more technical view of running processes, including process IDs (PIDs).
5. **Services**: Windows services and whether they're running or stopped.

## Native Windows Security

- Windows has built-in security tools to help protect your system from threats like malware, unsafe apps and unauthorised network access.
- These are turned on by default and let you monitor and control your system's security.

### Windows Security

The **Windows Security** app is the central dashboard for Windows' built-in protection. It has four main sections:

- **Virus & threat protection**: Finds and removes malicious software using real-time protection and scans.
- **Firewall & network protection**: Controls incoming and outgoing network traffic to help stop unauthorised access.
- **App & browser control**: Protects you from potentially unsafe apps, files and websites.
- **Device security**: Hardware-based protections that help secure the system.

### Windows Defender Firewall

- **Windows Defender Firewall** is Windows' built-in firewall. (Microsoft Defender Antivirus is the separate built-in antivirus.)
- It has three network profiles:
    - **Domain**: Used when the system is connected to an organisation's domain network.
    - **Private**: For trusted networks, like a home or lab network.
    - **Public**: For untrusted networks, like public Wi-Fi.

## Summary

- **Desktop**: The main workspace where files, folders and shortcuts live.
- **Taskbar**: The strip that gives access to apps, tools, settings and notifications.
- **Start Menu**: The main way to open apps, settings and power options, shown by the Windows logo.
- **Search**: A quick way to find apps, settings and files by typing.
- **File Explorer**: The built-in tool to browse, manage and organise files and folders.
- **Windows Update**: The built-in tool that keeps the OS, built-in apps and security features up to date.
- **Microsoft Store**: The built-in app for installing trusted applications.
- **Windows Settings**: The central place for system, device, personalisation and security settings.
- **Control Panel**: The legacy interface for system configuration options.
- **Task Manager**: Shows what's happening on your system in real time.
- **Windows Security**: The central dashboard for Windows' built-in security tools.
- **Windows Defender Firewall**: The firewall that helps protect your system from unauthorised network traffic.
